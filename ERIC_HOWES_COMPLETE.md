### writingStyle.md

#### Writing Style Rules — AI Language Avoidance & Human Tone

This file defines how all written materials (resumes, cover letters, application text fields) must sound. Referenced by `evaluate_and_generate.md`. Every document generated must pass these rules.

---

##### BANNED PHRASES — Never Use These

###### Generic Openers
- "I am writing to express my interest in..."
- "I am excited to apply for..."
- "I am eager to..."
- "I am uniquely positioned to..."
- "As a highly motivated professional..."
- "I am passionate about..."

###### Overused Corporate Buzzwords
- "Leverage" / "leveraging" (use "use," "apply," "put to work")
- "Synergy" / "synergies"
- "Delve" / "delve into" (most flagged AI word)
- "Foster" / "fostering"
- "Cutting-edge"
- "Dynamic"
- "Robust"
- "Pivotal"
- "Multifaceted"
- "Tapestry"
- "Beacon of"
- "Intricate interplay"
- "Holistic"
- "Paradigm"
- "Actionable insights"
- "Bolstered"
- "Crucial"
- "Vibrant"
- "Underscore" / "underscoring"
- "Garner" / "garnered"
- "Showcasing"
- "Align with" / "aligned with"
- "Enhance" / "enhancing"
- "Landscape" (as in "the marketing landscape")
- "Testament" (as in "a testament to")

###### Resume-Specific AI Tells
- "Results-driven professional"
- "Proven track record" (say what you actually proved instead)
- "Demonstrated ability to execute deliverables"
- "Proven expertise in driving impactful solutions"
- "Highly motivated individual"
- "Team player with strong communication skills"
- "Seeking to utilize my skills in a dynamic environment"

###### Structural AI Tells to Avoid
- "Furthermore," "Moreover," "Additionally" as paragraph starters
- "In today's fast-paced world/landscape"
- "In the ever-evolving world of..."
- "It's important to note that..."
- Every bullet point starting with the same sentence structure
- Lists where every item is the exact same length
- Overly parallel constructions repeated throughout

###### Dash Rules
AI leans on dashes constantly as a crutch for connecting ideas. Forcing full sentence rewrites produces tighter, more direct prose.
- **Cover letters: ZERO dashes of any kind.** No em dashes, no hyphens used as pauses, no double hyphens. If you would use a dash, rewrite the sentence so it doesn't need one.
- **Resumes: use sparingly.** One or two em dashes per page max, and only when the alternative reads worse. Never use them as a default connector between clauses.

###### Tone Markers That Scream AI
- No contractions anywhere (use "I'm," "I've," "don't" naturally)
- Perfectly balanced "on one hand / on the other hand" structures
- Everything sounds like a press release
- Generic enthusiasm without specific details
- Superlatives without evidence ("exceptional," "outstanding," "remarkable")
- Over-qualifying: "arguably," "it could be said that," "from my perspective"

---

##### HOW TO SOUND HUMAN

###### Do This Instead
1. **Use contractions naturally:** "I've built" not "I have built," "I'm drawn to" not "I am drawn to"
2. **Vary sentence length:** Mix short punchy sentences with longer detailed ones
3. **Be specific, not generic:** "I spent three months migrating our SMS system from Vendor A to Vendor B, saving $X annually" beats "I drove significant cost savings through strategic vendor optimization"
4. **Use active, direct language:** "I built this" not "This was developed under my leadership"
5. **Include real context:** Name actual tools, actual projects, actual challenges you faced
6. **Write asymmetric bullets:** Not every bullet needs to be the same length or follow the same pattern
7. **Show personality through specificity:** The more concrete your details, the more human you sound
8. **Start paragraphs differently:** Don't begin consecutive paragraphs with similar structures
9. **Occasional informality in cover letters:** It's okay to write like a smart professional talking, not a robot generating text

###### The Perplexity / Burstiness Rule
AI detection tools measure two things:
- **Perplexity:** How predictable is the next word? Low perplexity = AI. Choose unexpected but accurate word choices.
- **Burstiness:** How varied are sentence lengths? Low burstiness = AI. Mix 5-word sentences with 25-word sentences.

---

##### Quality Check (Run on Every Document)
- Are there zero AI-giveaway phrases? (Check against banned list above)
- Does it read like a human wrote it? (Contractions, varied sentence length, specific details)
- Are bullet points asymmetric in length and structure?
- Do paragraphs start differently from each other?
- Is the language specific rather than generic?
- Would this pass an AI detection tool?

#### Evaluate & Generate — Fit Scoring + Resume + Cover Letter

##### Purpose

One pass per job. Fit scoring and material generation run together so there's no waiting between steps.

##### Files to Read

##### Files This Task Writes

  - `Job_Applications/{CompanyName}/{LastName}_{FirstName}_Resume_{CompanyName}.docx` + `.pdf`
  - `Job_Applications/{CompanyName}/{LastName}_{FirstName}_CoverLetter_{CompanyName}.docx` + `.pdf`
  - Appended `## FIT EVALUATION` block in the JD file
- Updated row in `tracker.csv` with new Status + Required/Wanted Fit Match %

---

##### Scope — What This Task Does
- Picks up every tracker row with status **JD DOWNLOADED**
- Reads each JD file
- Scores fit against `workHistory.md` + `preferences.md`
- Updates status to GOOD FIT / BORDERLINE FIT / BORDERLINE FIT - HIGH COMP / DISQUALIFIED / MISSING JOB DESCRIPTION
- For GOOD FIT and BORDERLINE FIT: generates tailored resume + cover letter
- Updates the tracker status to MATERIALS READY / MATERIALS READY - BORDERLINE after materials are saved

##### Scope — What This Task Does NOT Do
- Does NOT search for jobs (use `find_jobs.py`)
- Does NOT fill out application forms
- Does NOT click Submit on any application

---

##### Combined Per-Row Process

For each row with status `JD DOWNLOADED`, run these steps in order:

###### Step 1 — Verify the JD File Matches the Row

1. Read the tracker row's Company (Col 1) and Role (Col 2).
2. Read the JD file's header (first ~30 lines).
3. If the JD's company doesn't match the tracker's company, OR the JD's title obviously refers to a different role than the tracker's Role column:
   - Delete the wrong JD file (or rename to `_deleted_<date>_*.bak` if delete fails)
   - Set Status = **MISSING JOB DESCRIPTION**, Notes = `Wrong JD deleted (was: '<actual JD title>'); needs re-download`
   - Skip to next row
4. If the JD file is missing or fewer than ~1,500 characters of real content:
   - Delete the stub file
   - Set Status = **MISSING JOB DESCRIPTION**, Notes = `Stub JD deleted; needs re-download`
   - Skip to next row

###### Step 2 — Location Check (Before Reading Full JD)
Apply the location filter from `preferences.md`:
- If `remote_ok = true` and the JD says fully remote / remote (US) / WFH → proceed
- If the role is in one of the user's `metro_cities` (or within the commute radius) → proceed
- Otherwise → Status = **DISQUALIFIED**, Notes = `Location: <city/state from JD> doesn't match preferences (remote_ok=<bool>, metro=<cities>)`. Move to next row.

###### Step 3 — Hard Disqualifier Check
- Does the JD require a credential the user doesn't have (PhD, MD, JD, PE license, active security clearance — anything in `preferences.md`'s `hard_credentials_to_skip`)? If yes, and there's no "or equivalent experience" softener nearby → Status = **DISQUALIFIED**, Notes = `Missing required credential: <credential>`. Move on.
- Does the role match an `auto_skip_title_patterns` regex? → Status = **DISQUALIFIED**, Notes = `Title auto-skip: <pattern>`. Move on.

###### Step 4 — Strip Prior Evaluations
If the JD file already has a `## FIT EVALUATION` block from a previous run, strip it before keyword counting. Otherwise your prior notes will inflate the score.

###### Step 5 — Score the Fit

1. **List Required qualifications** from the JD (anything under "Required," "Must have," "Minimum qualifications," etc.). If not labeled, treat hard skills, years of experience, and credentials as Required.
2. **List Preferred qualifications** ("Preferred," "Nice to have," "Bonus").
3. For each Required item, check `workHistory.md`:
   - ✅ = Have it (cite the specific role/project from `workHistory.md`)
   - ⚠️ = Partial / transferable
   - ❌ = Don't have it
4. Same for Preferred.
5. Compute:
   - `Required match % = (✅ count) / (total Required) × 100`
   - `Preferred match % = (✅ count) / (total Preferred) × 100`

###### Step 6 — Decide Status

Read these salary thresholds from `preferences.md`:
- `min_salary_usd` — anything clearly below this when comp is listed is auto-DQ
- `high_comp_threshold_usd` — at or above this, marginal fits get HIGH COMP flag

Decision rules:
- **Required ≥ 80% AND Preferred ≥ 50%** → Status = **JD DOWNLOADED - GOOD FIT**
- **Required 60–79% OR Preferred 30–49%, AND salary ≥ `high_comp_threshold_usd`** → Status = **JD DOWNLOADED - BORDERLINE FIT - HIGH COMP**
- **Required 60–79% OR Preferred 30–49%** → Status = **JD DOWNLOADED - BORDERLINE FIT**
- **Required < 60%** → Status = **DISQUALIFIED** with reason
- **Missing non-substitutable credential** → Status = **DISQUALIFIED**
- **Salary listed and below `min_salary_usd`** → Status = **DISQUALIFIED** with reason
- **Job posted > 7 days ago** → Status = **STALE**

###### Step 7 — Write the Evidence Block to the JD File

Append this block to the JD file (`Job_Description_{CompanyName}.txt`). Every row that gets GOOD FIT / BORDERLINE / DISQUALIFIED needs this block populated:

```
##### FIT EVALUATION
###### JD ↔ Row Match
- Tracker Role: <Col 2 value>
- JD Title: <from JD header>
- Match: yes / no

###### Location
- JD location: <signal>
- Preferences: remote_ok=<bool>, metro_cities=<list>
- Decision: pass / fail (with reason)

###### Required Qualifications
- "<quoted Required item ≤15 words>" — ✅/⚠️/❌ — <workHistory.md citation or gap>
- (repeat for every Required item)

###### Preferred Qualifications
- "<quoted Preferred item>" — ✅/⚠️/❌ — <citation or gap>

###### Match Math
- Required: X / Y = NN%
- Preferred: X / Y = NN%

###### Recommendation
- Status: <STATUS>
- One-sentence reason

###### Key Strengths for This Role
- 2–4 bullets from workHistory.md

###### Key Gaps
- 0–4 bullets, plain English
```

###### Step 8 — Update the Tracker

Update ONLY Column 3 (Status), Column 9 (Required Fit Match), Column 10 (Wanted Fit Match), and Column 11 (Notes). NEVER overwrite Column 2 (Role).

- Required Fit Match = `NN%`
- Wanted Fit Match = `NN%`
- Notes = short summary (1-2 sentences)
- If Salary Range (Col 8) was `—` and the JD lists comp explicitly, fill it in. Don't guess.

###### Step 9 — If GOOD FIT / BORDERLINE FIT / BORDERLINE FIT - HIGH COMP, Generate Materials

Skip this step for DISQUALIFIED / MISSING JOB DESCRIPTION / STALE.

###### 9a — Resume

Generate a tailored resume from `workHistory.md` + the JD.

**Tailoring process** (do this every time, fresh from `workHistory.md`):
1. Read the JD carefully. Identify the 5-7 most important keywords.
2. Map every Required and Preferred qualification to a specific role / project / metric in `workHistory.md`. Pull from ALL roles, not just the most recent.
3. Write the Professional Summary in 3–5 sentences, third person. Open with a positioning statement: category of leader, depth, what makes the user distinctly valuable for THIS role. Mirror the JD's exact tool / platform names. End with a sentence that connects the user to this company's specific challenge.
4. Write each role's scope paragraph to emphasize the angle most relevant to THIS JD. Same facts, different emphasis. Never copy-paste a scope paragraph from a prior resume.
5. Write bullets that directly address JD requirements. Every bullet must connect to something the JD asks for. Vary bullet length intentionally — short and long mixed.
6. Use the user's exact tool names from `workHistory.md`; use the JD's exact terminology where it differs from generic versions.
7. For BORDERLINE roles: identify the gap, find the closest proxy experience, and lead with it. Don't hide the gap, but don't call it out either.
8. **If a JD requirement has no match in `workHistory.md`,** do NOT invent or stretch. Flag it: "The JD requires X. I don't see a direct match. Closest proxy is Y — proceed with proxy, or should I ask?"

**Length:**
- Target **2 full pages.** If the draft is short, expand using JD-relevant content from `workHistory.md`. Don't pad with generic filler.
- 3 pages only when the seniority / technical depth genuinely warrants it. Never exceed 3 pages.

**Structure (in order):**
1. Header — Name (from `profile.md`), target job title, contact line
2. Professional Summary — 3-5 sentences, third person
3. Professional Experience — most relevant role first (default reverse-chronological, but relevance beats recency)
4. Education

**Anti-patterns to avoid** — see `writingStyle.md` for the full banned list. Quick reminder: no "results-driven," no "leveraged," no "spearheaded," no "passionate about," no generic openers, no first-person summary.

**Formatting (DOCX):**
- Arial throughout
- Body 10pt, color `#1A1A2E` (deep navy, not pure black)
- Accent blue `#2563EB` for the target title line, section divider rules, and company names in role headers
- Medium gray `#6B7280` for contact line, locations, dates
- Single-column layout — NEVER use `TextBox`, floating elements, or multi-column section. Use borderless `Table` for any side-by-side effect (see `guardrails.md` DOCX rules).
- Italic scope paragraph after every role title
- Tab stop at `pos=9360` for right-aligned dates (US Letter width)
- Margins: top/bottom 0.5", left/right 0.75"

**Filename:** `{LastName}_{FirstName}_Resume_{CompanyName}.docx` and `.pdf`, saved to `Job_Applications/{CompanyName}/`.

###### 9b — Cover Letter

Generate a tailored cover letter from `workHistory.md` + the JD.

**Hard constraints:**
- **250 words max** in the body. Count them.
- **3 paragraphs only.** No headers, no bullets, no lists inside the body.
- **Zero dashes of any kind.** No em dashes, no hyphens as pauses. If you'd use a dash, rewrite.
- **Never open with "I"** as the first word. Never open by naming the company or job title.
- **Use contractions throughout:** I've, I'm, that's, it's, they're.
- **Vary sentence length deliberately** — mix 5-word sentences with 20-word ones.
- **Start at least one sentence with "And" or "But"** for natural rhythm.
- **Use the company name no more than once** in the body.
- **Include ONE specific micro-story** from `workHistory.md` — a real project, a turning point, a specific decision. Something only the user would know.
- **Anchor every claim to a specific number** from `workHistory.md`. No invented metrics.
- **Mirror one piece of JD language** naturally.
- **End with a confident, direct next step.** No "thank you for your time," no "I look forward to hearing from you."

**Structure:**
- Header (name, contact line, blue accent rule under contact — matches resume header)
- Date
- Hiring Manager
- Company Name
- Re: <exact job title>
- 3 body paragraphs:
  - Paragraph 1: direct statement of specific value, or sharp observation connecting the user's experience to the company's problem
  - Paragraph 2: evidence anchored to specific numbers from `workHistory.md`, includes the micro-story
  - Paragraph 3: bridge and close — "Why this role?" + "Why me?" implicit answers, confident next step
- Sincerely, {Full Name}

**Formatting (DOCX):**
- Arial 11pt, color `#1A1A2E`
- 1-inch margins all around
- Same single-column / no-TextBox / no-multi-column rules as the resume
- Header block (name + contact line) styled identically to the resume header for visual consistency

**Filename:** `{LastName}_{FirstName}_CoverLetter_{CompanyName}.docx` and `.pdf`, saved to `Job_Applications/{CompanyName}/`.

**Post-generation flagging:**
After writing, save a `CoverLetter_Notes_{CompanyName}.txt` in the same folder containing:
1. Any assumption made about the user's experience that they should verify
2. The 3 sentences most at risk of sounding AI-written (so the user can hand-rewrite them in their own voice)

###### Step 10 — Convert DOCX → PDF and Validate

For both resume and cover letter:
1. Convert `.docx` → `.pdf` (LibreOffice in headless mode works in sandboxed environments).
2. Open the PDF and verify:
   - No duplicate text side-by-side (the floating-element bug — if it appears, rebuild using Tables only and re-convert)
   - Colors render correctly (blue accent line, navy text, gray contact line)
   - Dates stay right-aligned, no content cut off at margins
   - The cover letter PDF has no placeholders left ([Company Name], [Date], [Job Title])

If anything fails, fix it in the `.docx` and reconvert before continuing.

###### Step 11 — Final Tracker Update

After BOTH the resume and cover letter PDFs pass validation, update the tracker:
- If status was GOOD FIT → set Status = **MATERIALS READY**
- If status was BORDERLINE FIT → set Status = **MATERIALS READY - BORDERLINE**
- If status was BORDERLINE FIT - HIGH COMP → set Status = **MATERIALS READY - BORDERLINE** (user reviews fit + comp before deciding to apply)

NEVER mark `MATERIALS READY` if either file failed validation. Leave the status at GOOD FIT / BORDERLINE and note the failure in the Notes column.

---

##### Output Summary
At the end of the run, present the user with:
- Count of rows processed
- Count by new status: GOOD FIT, BORDERLINE FIT, BORDERLINE - HIGH COMP, DISQUALIFIED, MISSING JOB DESCRIPTION, STALE
- Count of resume + cover letter pairs generated
- Any rows that need user attention (NEEDS INFO, flagged assumptions, validation failures)

---

##### Notes
- This task replaces the separate "evaluate fit" and "generate materials" steps. They're combined here so each job gets evaluated and (if it passes) tailored in one pass.
- Every resume and cover letter is fresh from `workHistory.md` + the JD. NEVER reuse content across companies.
- If `workHistory.md` is missing details a strong resume needs, pause and ask the user before generating.

#!/usr/bin/env python3
"""
build_documents.py — Build a tailored resume and cover letter (.docx + .pdf)
from a per-company content file.

The content file is plain JSON written fresh for each job from workHistory.md
and the job description. This script only handles layout; it never adds or
changes wording.

Usage:
  python scripts/build_documents.py Job_Applications/ADIGlobalDistribution/content.json

Formatting follows evaluate_and_generate.md and guardrails.md:
  - Arial, navy body text, blue accents, gray contact/dates
  - Single column, no text boxes, no floating elements, no multi-column sections
  - Right-aligned dates with a tab stop at 6.5" (9360 twips)
"""

import json
import subprocess
import sys
from pathlib import Path

from docx import Document
from docx.enum.text import WD_TAB_ALIGNMENT
from docx.oxml import OxmlElement
from docx.oxml.ns import qn
from docx.shared import Inches, Pt, RGBColor

NAVY = RGBColor(0x1A, 0x1A, 0x2E)
BLUE = RGBColor(0x25, 0x63, 0xEB)
GRAY = RGBColor(0x6B, 0x72, 0x80)
FONT = "Arial"

NAME = "Eric Howes"
CONTACT = "Orem, UT  |  (801) 367-6743  |  howesfamilyhomes@gmail.com  |  linkedin.com/in/eric-howes-utah"
FILE_PREFIX = "Howes_Eric"


# ---------- low-level helpers ----------

def set_base_style(doc, size_pt):
    style = doc.styles["Normal"]
    style.font.name = FONT
    style.font.size = Pt(size_pt)
    style.font.color.rgb = NAVY
    # Make Arial apply to East Asian text slots too, so Word doesn't swap fonts.
    style.element.rPr.rFonts.set(qn("w:eastAsia"), FONT)
    style.paragraph_format.space_after = Pt(0)
    style.paragraph_format.space_before = Pt(0)


def set_margins(doc, top, bottom, left, right):
    for section in doc.sections:
        section.page_width = Inches(8.5)
        section.page_height = Inches(11)
        section.top_margin = Inches(top)
        section.bottom_margin = Inches(bottom)
        section.left_margin = Inches(left)
        section.right_margin = Inches(right)


def add_run(paragraph, text, size=None, bold=False, italic=False, color=NAVY):
    run = paragraph.add_run(text)
    run.font.name = FONT
    run.bold = bold
    run.italic = italic
    run.font.color.rgb = color
    if size:
        run.font.size = Pt(size)
    return run


def add_bottom_rule(paragraph, color_hex="2563EB", size_eighths=8):
    """Draw a horizontal line under a paragraph using a paragraph border (not a shape)."""
    p_pr = paragraph._p.get_or_add_pPr()
    borders = OxmlElement("w:pBdr")
    bottom = OxmlElement("w:bottom")
    bottom.set(qn("w:val"), "single")
    bottom.set(qn("w:sz"), str(size_eighths))
    bottom.set(qn("w:space"), "1")
    bottom.set(qn("w:color"), color_hex)
    borders.append(bottom)
    p_pr.append(borders)


def add_header_block(doc, title_line=None):
    name = doc.add_paragraph()
    add_run(name, NAME.upper(), size=20, bold=True)

    if title_line:
        title = doc.add_paragraph()
        add_run(title, title_line, size=11, bold=True, color=BLUE)

    contact = doc.add_paragraph()
    add_run(contact, CONTACT, size=9, color=GRAY)
    contact.paragraph_format.space_after = Pt(6)
    add_bottom_rule(contact)


def add_section_heading(doc, text):
    heading = doc.add_paragraph()
    heading.paragraph_format.space_before = Pt(10)
    heading.paragraph_format.space_after = Pt(4)
    add_run(heading, text.upper(), size=10.5, bold=True, color=BLUE)
    add_bottom_rule(heading, size_eighths=4)


def add_bullet(doc, text):
    bullet = doc.add_paragraph(style="List Bullet")
    bullet.paragraph_format.space_after = Pt(2)
    bullet.paragraph_format.left_indent = Inches(0.25)
    add_run(bullet, text)


# ---------- resume ----------

def build_resume(content, out_path):
    doc = Document()
    set_base_style(doc, 10)
    set_margins(doc, top=0.5, bottom=0.5, left=0.75, right=0.75)

    add_header_block(doc, content["title_line"])

    add_section_heading(doc, "Professional Summary")
    summary = doc.add_paragraph()
    add_run(summary, content["summary"])

    if content.get("skills"):
        add_section_heading(doc, "Core Skills")
        skills = doc.add_paragraph()
        add_run(skills, "  |  ".join(content["skills"]))

    add_section_heading(doc, "Professional Experience")
    for role in content["roles"]:
        header = doc.add_paragraph()
        header.paragraph_format.space_before = Pt(6)
        header.paragraph_format.tab_stops.add_tab_stop(Inches(6.5), WD_TAB_ALIGNMENT.RIGHT)
        header.paragraph_format.keep_with_next = True
        add_run(header, role["title"], bold=True)
        add_run(header, "  |  ")
        add_run(header, role["company"], bold=True, color=BLUE)
        add_run(header, "\t" + role["dates"], color=GRAY)

        location = doc.add_paragraph()
        location.paragraph_format.keep_with_next = True
        add_run(location, role["location"], size=9, color=GRAY)

        if role.get("scope"):
            scope = doc.add_paragraph()
            scope.paragraph_format.space_after = Pt(2)
            scope.paragraph_format.keep_with_next = True
            add_run(scope, role["scope"], italic=True)

        for text in role["bullets"]:
            add_bullet(doc, text)

    if content.get("earlier"):
        add_section_heading(doc, "Earlier Experience")
        for text in content["earlier"]:
            add_bullet(doc, text)

    add_section_heading(doc, "Education & Certifications")
    for text in content["education"]:
        line = doc.add_paragraph()
        line.paragraph_format.space_after = Pt(2)
        add_run(line, text)

    doc.save(out_path)


# ---------- cover letter ----------

def build_cover_letter(content, out_path):
    letter = content["cover_letter"]

    doc = Document()
    set_base_style(doc, 11)
    set_margins(doc, top=1, bottom=1, left=1, right=1)

    add_header_block(doc)

    for text in [letter["date"], "", "Hiring Manager", letter["company"], "",
                 "Re: " + letter["role"], ""]:
        line = doc.add_paragraph()
        add_run(line, text)

    for text in letter["paragraphs"]:
        body = doc.add_paragraph()
        body.paragraph_format.space_after = Pt(10)
        body.paragraph_format.line_spacing = 1.1
        add_run(body, text)

    closing = doc.add_paragraph()
    add_run(closing, "Sincerely,")
    signature = doc.add_paragraph()
    signature.paragraph_format.space_before = Pt(6)
    add_run(signature, NAME)

    doc.save(out_path)

def convert_to_pdf(docx_path):
    subprocess.run(
        ["soffice", "--headless", "--convert-to", "pdf", "--outdir",
         str(docx_path.parent), str(docx_path)],
        check=True,
        stdout=subprocess.DEVNULL,
        stderr=subprocess.DEVNULL,
    )
    return docx_path.with_suffix(".pdf")


def main():
    if len(sys.argv) != 2:
        sys.exit("Usage: python scripts/build_documents.py <path to content.json>")

        pdf = convert_to_pdf(path)
        print(f"Built {path.name} and {pdf.name}")


if __name__ == "__main__":
    main()

def pascal_company(name: str) -> str:

def load_tracker():

def auto_skip_title(title: str, patterns: list) -> bool:

def extract_salary_top_usd(salary_str: str):
    if not salary_str:
        return None
    nums = []
    for m in re.finditer(r"\$?\s*(\d{2,3})(?:[,.]?(\d{3}))?\s*([kK])?", salary_str):
        whole, thousand, k = m.groups()
        if k:
            val = int(whole) * 1000
        elif thousand:
            val = int(whole) * 1000 + int(thousand)
        else:
            n = int(whole)
            val = n * 1000 if n < 1000 else n
        nums.append(val)
    return max(nums) if nums else None


def qualify_jd(title: str, jd_text: str, salary_str: str, prefs: dict):
    """Conservative pre-filter. Returns (verdict, reason).
    verdict ∈ {'OK', 'SKIP'}. False-skip is worse than false-save — the
    AI evaluate task can still DISQUALIFY a saved row.
    """
    if not jd_text:
        return "OK", ""

    title_lower = title.lower()
    jd_lower = jd_text.lower()

    # Hard credential gates
    softeners = re.compile(
        r"or\s+(equivalent|relevant|comparable)\s+(experience|expertise|education)"
        r"|or\s+\d+\s*\+?\s*years?\s+of"
        r"|or\s+equivalent\b"
        r"|preferred\b|nice[- ]to[- ]have\b|bonus\b",
        re.IGNORECASE,
    )
    hard_creds = [
        (r"\b(ph\.?\s*d|doctorate|doctoral degree)\b", "PhD"),
        (r"\bm\.?d\b\s*(degree|required)", "MD"),
        (r"\bj\.?d\b\s*(degree|required)", "JD"),
        (r"\bp\.?\s*e\.?\s*license\b", "PE license"),
        (r"\b(active|current)\s+(top secret|ts/sci|secret)\s+(clearance|security clearance)", "active security clearance"),
    ]
    user_skip_creds = {c.lower() for c in prefs.get("hard_credentials_to_skip", [])}
    for pat, label in hard_creds:
        if label.lower() not in str(user_skip_creds).lower():
            continue
        m = re.search(pat, jd_lower)
        if not m:
            continue
        tail = jd_lower[m.end():m.end() + 250]
        head = jd_lower[max(0, m.start() - 100):m.start()]
        if softeners.search(tail) or softeners.search(head):
            continue
        return "SKIP", f"hard credential: {label} required"

    # Skill keyword sanity — JD must mention at least one skill the user has
    skill_kws = [kw.lower() for kw in prefs.get("skill_keywords", [])]
    if skill_kws:
        if not any(re.search(rf"\b{re.escape(kw)}\b", jd_lower) for kw in skill_kws):
            return "SKIP", "no relevant skill keywords in JD body"

    # Salary floor
    min_salary = prefs.get("compensation", {}).get("min_salary_usd", 0)
    top = extract_salary_top_usd(salary_str)
    if top is None:
        m = re.search(
            r"\$\s?\d{2,3}[,.]?\d{3}\s*[-–to]+\s*\$?\s?\d{2,3}[,.]?\d{3}",
            jd_text, re.IGNORECASE,
        )
        if m:
            top = extract_salary_top_usd(m.group(0))
    if top is not None and min_salary and top < min_salary:
        return "SKIP", f"top salary ${top:,} below floor ${min_salary:,}"

    # Title auto-skip
    if auto_skip_title(title, prefs.get("auto_skip_title_patterns", [])):
        return "SKIP", "auto-skip title pattern"

    return "OK", ""


def location_verdict(jd_text: str, card_raw: str, prefs: dict) -> str:
    """Returns 'collect' (proceed) or 'skip' or 'ambiguous'."""
    loc = prefs.get("location", {})
    remote_ok = loc.get("remote_ok", False)
    hybrid_ok = loc.get("hybrid_ok", False)
    metro_cities = {c.lower() for c in loc.get("metro_cities", [])}

    txt = (jd_text + " " + (card_raw or "")).lower()

    remote_patterns = [
        r"\bfully remote\b", r"\bremote[- ]only\b", r"\bremote[- ]first\b",
        r"\bwork from anywhere\b", r"\bwork from home\b", r"\bwfh\b",
        r"\btelecommute\b|\btelecommuting\b", r"\b100\s*%?\s*remote\b",
        r"\bremote,\s*(united states|us|usa)\b",
    ]
    is_remote = any(re.search(p, txt) for p in remote_patterns) or re.search(r"\b(remote.*us|us.*remote)\b", txt)
    if is_remote and remote_ok:
        return "collect"

    for city in metro_cities:
        if re.search(rf"\b{re.escape(city)}\b", txt):
            return "collect"

    if "hybrid" in txt:
        return "collect" if hybrid_ok else "skip"
    if "onsite" in txt or "on-site" in txt or "in-office" in txt:
        return "skip"
    if re.search(r"\bremote\b", txt) and not re.search(r"remote:\s*no\b", txt):
        return "collect" if remote_ok else "ambiguous"

    return "ambiguous"


FORBIDDEN_URL_PATTERNS = [r"linkedin\.com/company/", r"/search\?"]

def forbidden_url(url: str) -> bool:
    if not url:
        return True
    u = url.strip().lower()
    if u.startswith(("chrome-error://", "chrome://", "about:", "data:", "javascript:")):
        return True
    return any(re.search(p, url) for p in FORBIDDEN_URL_PATTERNS)


def clean_url_through_google(u: str) -> str:
    try:
        p = urlparse(u)
    except Exception:
        return u
    if "google.com" in p.netloc:
        qs = parse_qs(p.query)
        for key in ("url", "q", "adurl"):
            if key in qs and qs[key]:
                inner = qs[key][0]
                if inner.startswith("http"):
                    return inner
    return u


def wait_for_not_captcha(page, log):
    banner_shown = False
    while True:
        url = page.url or ""
        try:
            body = page.evaluate("document.body ? document.body.innerText.slice(0, 2000) : ''")
        except Exception:
            body = ""
        is_captcha = (
            "sorry/index" in url or "consent.google" in url
            or "unusual traffic" in (body or "").lower()
        )
        if not is_captcha:
            if banner_shown:
                log.write("  [captcha cleared, resuming]\n")
                log.flush()
            return
        if not banner_shown:
            print("!! CAPTCHA detected — solve in browser, script will auto-resume.", flush=True)
            log.write("  [captcha detected, waiting]\n")
            log.flush()
            banner_shown = True
        time.sleep(5)


def run_scroll_loop(page):
    js = """
    (async () => {
      let last = 0, stable = 0;
      for (let i = 0; i < 60; i++) {
        window.scrollTo(0, document.body.scrollHeight);
        await new Promise(r => setTimeout(r, 900));
        const n = document.querySelectorAll('div.EimVGf').length;
        if (n === last) { if (++stable >= 4) break; } else { stable = 0; last = n; }
      }
      return document.querySelectorAll('div.EimVGf').length;
    })();
    """
    try:
        return page.evaluate(js) or 0
    except PWError:
        return page.evaluate("document.querySelectorAll('div.EimVGf').length") or 0

def click_card_and_extract(page, card_idx, card_title):

def google_jobs_url(query: str, prefs: dict) -> str:
    loc = prefs.get("location", {})
    primary = f"{loc.get('primary_city', '')} {loc.get('primary_state', '')}".strip()
    location_part = primary if primary else "United States"
    full_query = f"{query} {location_part}".strip()
    chips = "htichips=date_posted:week,remote_jobs:1" if loc.get("remote_ok") else "htichips=date_posted:week"
    return f"https://www.google.com/search?q={quote_plus(full_query)}&ibp=htl;jobs&{chips}"


def save_jd_and_append(card, jd_text, apply_url, prefs, fieldnames, existing, skip_companies, log):
    title = (card.get("title") or "").strip()
    company = (card.get("company") or "").strip()
    if not title or not company:
        return False

    company_pascal = pascal_company(company)
    key = (company.lower(), title.lower())
    if key in existing:
        log.write(f"  [dup] {company} — {title}\n")
        return False
    if company.lower() in skip_companies:
        log.write(f"  [skip-company-applied] {company} — {title}\n")
        return False

    # Location filter
    loc_verdict = location_verdict(jd_text, card.get("raw", ""), prefs)
    if loc_verdict == "skip":
        log.write(f"  [loc-skip] {company} — {title}\n")
        return False

    # Qualification pre-filter (conservative)
    salary_match = re.search(r"\$[\d,]+\s*(?:[-–to]+\s*\$[\d,]+)?(?:\s*[kK])?", jd_text)
    salary_str = salary_match.group(0) if salary_match else ""
    verdict, reason = qualify_jd(title, jd_text, salary_str, prefs)
    if verdict == "SKIP":
        append_tracker_row(fieldnames, company, title, apply_url, "Google Jobs",
                           salary_str, f"Auto-skip: {reason}", status="DISQUALIFIED")
        existing.add(key)
        log.write(f"  [dq] {company} — {title} — {reason}\n")
        return False

    # Save JD
    folder = JOBS_DIR / company_pascal
    folder.mkdir(parents=True, exist_ok=True)
    jd_path = folder / f"Job_Description_{company_pascal}.txt"
    header = (
        f"# {company} — {title}\n"
        f"# Source: Google Jobs\n"
        f"# Apply URL: {apply_url}\n"
        f"# Saved: {TODAY.isoformat()}\n"
        f"\n"
    )
    jd_path.write_text(header + jd_text, encoding="utf-8")

    notes = f"Found via Google Jobs on {TODAY.isoformat()}"
    append_tracker_row(fieldnames, company, title, apply_url, "Google Jobs", salary_str, notes)
    existing.add(key)
    log.write(f"  [save] {company} — {title}\n")
    print(f"  saved: {company} — {title}", flush=True)
    return True

def run_google_pass(page, prefs, fieldnames, existing, skip_companies, log, smoke=False):
    titles = prefs.get("target_titles", [])
    if smoke:
        titles = titles[:1]
    queries = list(titles) + list(prefs.get("boolean_queries", []))
    if smoke:
        queries = queries[:1]

    saved = 0
    for i, query in enumerate(queries):
        url = google_jobs_url(query, prefs)
        print(f"\n[{i+1}/{len(queries)}] {query}", flush=True)
        log.write(f"\n[query {i+1}] {query}\n  url: {url}\n")
        try:
            page.goto(url, wait_until="domcontentloaded", timeout=30000)
        except (PWTimeout, PWError) as e:
            log.write(f"  navigation failed: {e}\n")
            continue
        time.sleep(2)
        wait_for_not_captcha(page, log)
        card_count = run_scroll_loop(page)
        log.write(f"  cards loaded: {card_count}\n")
        if card_count == 0:
            continue

        cards = enumerate_cards(page)
        for card in cards:
            try:
                result = click_card_and_extract(page, card["idx"], card.get("title", ""))
                if not isinstance(result, dict) or "jdText" not in result:
                    continue
                jd_text = result.get("jdText", "")
                apply_links = result.get("applyLinks", [])
                apply_url = ""
                for a in apply_links:
                    cleaned = clean_url_through_google(a.get("href", ""))
                    if not forbidden_url(cleaned):
                        apply_url = cleaned
                        break
                if save_jd_and_append(card, jd_text, apply_url, prefs, fieldnames,
                                      existing, skip_companies, log):
                    saved += 1
            except (PWTimeout, PWError) as e:
                log.write(f"  card error: {e}\n")
                continue
        wait_for_not_captcha(page, log)

    return saved


def main():
    parser = argparse.ArgumentParser()
    parser.add_argument("--smoke-test", action="store_true",
                        help="Run one query only, for sanity-check")
    parser.add_argument("--no-headed", action="store_true",
                        help="Run headless (captchas will block the script)")
    args = parser.parse_args()

    prefs = load_preferences()
    _, fieldnames, existing, skip_companies = load_tracker()

    log_path = BASE_DIR / f"find_jobs_log_{TODAY.isoformat()}.txt"
    with open(log_path, "a", encoding="utf-8") as log:
        log.write(f"\n=== {TODAY.isoformat()} run ===\n")
        with sync_playwright() as pw:
            browser = pw.chromium.launch(headless=args.no_headed)
            context = browser.new_context()
            page = context.new_page()

            saved = run_google_pass(page, prefs, fieldnames, existing, skip_companies, log,
                                    smoke=args.smoke_test)

            browser.close()

        log.write(f"\n=== run complete — saved {saved} new rows ===\n")
        print(f"\nDone. Saved {saved} new rows. Log: {log_path.name}", flush=True)


if __name__ == "__main__":
    main()
